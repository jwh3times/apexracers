# Development flow

The flow itself is `.agents/skills/ship/settings/dev-flow.md`, and `AGENTS.md` summarizes it. This file holds what this repository
adds.

## Branch types

- `research`
- `investigate`

## Pull request template

`.github/PULL_REQUEST_TEMPLATE.md` opens with a `Closes #` line: complete it, or change it to
`Part of #N`. A waived PR replaces it with its `Flow waived by the user:` line, and other exempt PRs
delete it.
